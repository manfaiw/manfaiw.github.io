## Getting started

1. Install NPUWorks from Microsoft Store on a supported Windows 11 device.
2. Open NPUWorks and wait for the runtime status to show **Running**.
3. Choose an available module. One module is active at a time.
4. Use the built-in Assistant, or connect a compatible application to
   `http://localhost:8888`.

The server listens on the local device by default. Its URL and port can be changed from the
Server page.

## Compatible interfaces

NPUWorks exposes local interfaces compatible with common OpenAI, Anthropic, and Ollama request
formats. The Server page shows which interfaces are enabled and the URL to use.

## Local data

Assistant conversations, attached files, generated responses, settings, and local access tokens
remain on the device. Conversation history can be deleted from the Assistant.
